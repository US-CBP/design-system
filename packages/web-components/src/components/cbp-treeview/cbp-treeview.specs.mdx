# cbp-treeview and cbp-treeview-item

## Purpose

* Display information in a tiered or nested display with parents and child relationships with the option to select items

## Functional Requirements

* rendered checkboxs will support unselected, selected, and indeterminate states that will be reflected on the treeview-item props
* Selecting a treeview-item will update the children (if any) to be selected as well as update the parents to the correct state
* The parent-child relationship is deteremined by nesting a cbp-treeview-item inside another cbp-treeview-item

## Technical Specifications

* Visual styling is only made 4 items deep, while parent/children can be deeper they will not be visually distinct past this depth.
    *specs (A -> B -> C -> D -> E)
* treeview emits an event 'treeviewSubmit' with the selected treeview items for cases where a form submit are not available or applicable
* treeview-item's that are parents will render with an 'expand' button to toggle display of any children as well as the number of children appended to the label prop
* 'Connectors' are used to visually display the parent/child relationship of elements in addition to indentation

### User Interactions

* Clicking on expand component will toggle hidden children
* Changes to rendered checkbox will be reflected in the state of the parent treeview-item props(checked/indeterminate)

### Responsiveness

* labels will wrap incases where nessecary, intended UX guidance is to keep this wrap to 2 lines where possible

### Accessibility

* All tree nodes are contained in or owned by an element with role "tree"
* Each element serving as a tree node has role "treeitem"
* Each Parent element contains or owns an element with role "group"
* Each element with the role treeitme that serves as a parent node has aria-expanded set to "false" when the node is in a closed state and "true" when it is in an open stat
* If tree supports selection of more than one node, the element with role "tree" has aria-multiselectable set to "true"
* the selection state for each selectable node is indicated with either aria-selected or aria-checked
* the element with role tree has either a visible label referenced by aria-labelledby or a value specified for aria-label
