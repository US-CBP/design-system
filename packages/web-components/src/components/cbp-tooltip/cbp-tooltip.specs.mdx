# cbp-tooltip

## Purpose

The Tooltip component allows for the disclosure of supplemental, non-essential information via a triggering element.

## Functional Requirements

* Tooltip is designed to wrap a slotted control, which can be any element.
* The tooltip positioning defaults above the control, centered, but may be positioned to the top, bottom, left or right, aligning to the starting or ending edge of the control or centered to the control.
* If the specified positioning results in the tooltip going off-screen, it will be repositioned on-screen by flipping its positioning and/or sliding it if needed.

## Technical Specifications

### User Interactions

* Tooltips are activated by hovering, focusing, or clicking the triggering element.
* When the tooltip is activated via mouse hover, it will be dismissed when no longer hovering the control or tooltip.
* When activated via focus or click, the tooltip will persist until it is closed via clicking the close button or clicking/tabbing away from the tooltip. 
* When closed, focus will return to the tooltip control.

### Responsiveness

* The tooltip is sized responsively by default and even if a width is specified by default, it uses a max-width: 100% so that it shall never exceed the size of the viewport.
* If the specified positioning results in the tooltip going off-screen, it will be repositioned on-screen by flipping its positioning and/or sliding it if needed.

### Accessibility

* The Tooltip trigger (host tag) has a `tabindex="0"` to make it focusable and keyboard navigable.
* The tooltip control has a `role="button"` applied.
* The actual tooltip has a `role="tooltip"`.

### Additional Notes and Considerations

* Tooltips should be used sparingly since hiding functionality should be avoided if at all possible.
* The Tooltip component needs additional testing with other elements and interactions with nested interactive elements.
