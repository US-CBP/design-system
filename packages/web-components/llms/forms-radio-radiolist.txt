# Forms/Radio/RadioList

## Examples


### Radio List

```tsx
({
  radios,
  label,
  description,
  fieldId,
  disabled,
  error,
  context,
  sx
}) => {
  return ` 
    <cbp-form-field group
      ${label ? `label="${label}"` : ''}
      ${description ? `description="${description}"` : ''}
      ${fieldId ? `field-id="${fieldId}"` : ''}
      ${disabled ? 'disabled' : ''}
      ${error ? 'error' : ''}
      ${context && context != 'light-inverts' ? `context="${context}"` : ''}
      ${sx ? `sx='${JSON.stringify(sx)}'` : ''}
    >
      ${generateRadios(context, radios)}
    </cbp-form-field>
  `;
}
```

  label,
  description,
  fieldId,
  disabled,
  error,
  context,
  sx

  return ` 
    <cbp-form-field group
      ${label ? `label="${label}"` : ''}

      ${fieldId ? `field-id="${fieldId}"` : ''}
