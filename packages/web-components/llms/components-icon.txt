# Components/Icon

## Examples


### Icon

```tsx
({
  name,
  color,
  size,
  rotate,
  accessibilityText,
  sx
}) => {
  return ` 
    <cbp-icon
      ${name ? `name=${name}` : ''}
      ${color ? `color=${color}` : ''}
      ${size ? `size=${size}` : ''}
      ${rotate ? `rotate=${rotate}` : ''}
      ${accessibilityText ? `accessibility-text=${accessibilityText}` : ''}
      ${sx ? `sx='${JSON.stringify(sx)}'` : ''}
    ></cbp-icon>
  `;
}
```
