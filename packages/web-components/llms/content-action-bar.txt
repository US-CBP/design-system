# Content/Action Bar

## Examples


### Action Bar

```tsx
({
  actionBarInfo,
  variant,
  context
}) => {
  return `  
    <cbp-action-bar 
      ${variant ? `variant="${variant}"` : ''}
      ${context && context != 'light-inverts' ? `context="${context}"` : ''}   
    >
      <cbp-typography 
        slot="cbp-action-bar-info"
        tag="div"
      >
        ${actionBarInfo}
      </cbp-typography>
      <cbp-button 
        fill="ghost"
        ${context && context != 'light-inverts' ? `context="${context}"` : ''}   
      >
        Action 1
      </cbp-button>
      <cbp-button 
        fill="ghost"
        color="secondary"
        ${context && context != 'light-inverts' ? `context="${context}"` : ''}     
      >
        Action 2
      </cbp-button>
    </cbp-action-bar>
  `;
}
```
