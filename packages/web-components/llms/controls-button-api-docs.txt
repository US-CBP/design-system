# cbp-button

## Overview

The Button component represents a UI control visually styled like a button, regardless of whether it renders (or wraps) a button or an anchor tag.

## Properties

| Property | Attribute | Description | Type | Default |
| --- | --- | --- | --- | --- |
| `accessibilityText` | `accessibility-text` | Specifies an accessible label for the button/link as an `aria-label` when the button does not contain label text or a sufficiently unique label. This text overrides the default label and is not additive to it. | `string` | `undefined` |
| `color` | `color` | The color of the button: primary, secondary, or danger. Defaults to "primary." | `"danger" | "primary" | "secondary"` | `'primary'` |
| `context` | `context` | Specifies the context of the component as it applies to the visual design and whether it inverts when light/dark mode is toggled. Default behavior is "light-inverts" and does not have to be specified. | `"dark-always" | "dark-inverts" | "light-always" | "light-inverts"` | `undefined` |
| `controlId` | `control-id` | Optionally specify the ID of the control here, which is used to generate related pattern node IDs and associate everything for accessibility | `string` | `createNamespaceKey('cbp-button')` |
| `controls` | `controls` | Specifies the DOM element that the button controls and results in the `aria-controls` attribute rendered on the button with the specified value. | `string` | `undefined` |
| `disabled` | `disabled` | Marks the rendered button/link in a disabled state when specified. | `boolean` | `undefined` |
| `download` | `download` | The `download` attribute of a link button; when present tells the browser to download the specified href URI instead of viewing or navigating to it. | `boolean | string` | `undefined` |
| `expanded` | `expanded` | Specifies if a controlled UI widget is expanded and results in `aria-pressed="true|false"` being placed on the button when specified. This property is usually used for progressive disclosure patterns such as accordions, menus, expand/collapse, etc., where focus remains on the control after the user action. | `"false" | "true"` | `undefined` |
| `fill` | `fill` | The visual fill of the button: solid, outline, or ghost. Defaults to "solid." | `"ghost" | "outline" | "solid"` | `'solid'` |
| `height` | `height` | Specifies the (min-)height of the button (in CSS units) when different from the default size. | `string` | `undefined` |
| `href` | `href` | The `href` attribute of a link button. | `string` | `undefined` |
| `name` | `name` | The `name` attribute of the button, which is passed as part of formData (as a key) for the the pressed submit button. | `string` | `undefined` |
| `pressed` | `pressed` | Specifies if the button is pressed and results in `aria-pressed="true|false"` being placed on the button when specified. Only valid on actual `button` elements. | `"false" | "true"` | `undefined` |
| `rel` | `rel` | The `rel` attribute of a link button. | `string` | `undefined` |
| `sx` | `sx` | Supports adding inline styles as an object | `any` | `{}` |
| `tag` | `tag` | Specifies whether the button is a true button element or "link button." | `"a" | "button"` | `'button'` |
| `target` | `target` | The `target` attribute of a link button. | `string` | `undefined` |
| `targetProp` | `target-prop` | The property on the target element being toggled by the button/control (e.g., "open"). | `string` | `undefined` |
| `type` | `type` | The `type` attribute of the button: button, submit, or reset. Defaults to "button." | `"button" | "reset" | "submit"` | `'button'` |
| `value` | `value` | The `value` attribute of the button, which is passed as part of formData (as a value) for the the pressed submit button. | `string` | `undefined` |
| `variant` | `variant` | Specifies a variant of the buttons, such as square for buttons with only an icon and call-to-action button. | `"circle" | "cta" | "square"` | `undefined` |
| `width` | `width` | Specifies the (min-)width of the button (in CSS units) when different from the default size. | `string` | `undefined` |

## Events

| Event | Description | Type |
| --- | --- | --- |
| `buttonClick` | A custom event emitted when the click event occurs for either a rendered button or anchor/link. | `CustomEvent<any>` |
| `componentLoad` | A custom event emitted when the component has completed loading and its internal lifecycles. | `CustomEvent<any>` |

## Slots

| Slot | Description |
| --- | --- |
|  | The button's label, which may contain markup such as icons, is placed in the default slot. |
|  | cbp-button-custom - Custom buttons/anchors may be slotted via named-slot, which prevents the web component from rendering its own tag. In such a case, component properties that render attributes directly onto the rendered button will have no effect, as they are expected to be supplied directly on the slotted element. |
