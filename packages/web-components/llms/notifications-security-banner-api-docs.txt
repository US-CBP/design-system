# cbp-security-banner

## Overview

The Security Banner displays at the top of a page to detail the highest security classification of content present on the page

## Properties

| Property | Attribute | Description | Type | Default |
| --- | --- | --- | --- | --- |
| `classification` | `classification` | Specifies the level of classification of the security banner | `"confidential" | "cui" | "unclassified"` | `'unclassified'` |
| `open` | `open` | Sepcifies if the content of the security banner is visible | `boolean` | `false` |
| `sx` | `sx` | Supports adding inline styles as an object | `any` | `{}` |
