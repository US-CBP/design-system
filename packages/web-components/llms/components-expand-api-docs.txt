# cbp-expand

## Overview

The Expand component is a standalone component used for progressive disclosure, organizing content under a relevant heading, which is used as a control for revealing and hiding its content.

## Properties

| Property | Attribute | Description | Type | Default |
| --- | --- | --- | --- | --- |
| `context` | `context` | Specifies the context of the component as it applies to the visual design and whether it inverts when light/dark mode is toggled. Default behavior is "light-inverts" and does not have to be specified. | `"dark-always" | "dark-inverts" | "light-always" | "light-inverts"` | `undefined` |
| `headingId` | `heading-id` | Specifies an optional `id` for the component item heading, also used to generate an `id` for the content wrapper. If this property is not specified, a unique string will automatically be generated. | `string` | `createNamespaceKey('cbp-expand')` |
| `headingLevel` | `heading-level` | The heading level of the expand item control. Defaults to h3. | `"h2" | "h3" | "h4" | "h5" | "h6"` | `'h4'` |
| `label` | `label` | The component control label. | `string` | `undefined` |
| `open` | `open` | Specifies whether the content is expanded and visible. | `boolean` | `false` |
| `sx` | `sx` | Supports adding inline styles as an object | `any` | `{}` |

## Events

| Event | Description | Type |
| --- | --- | --- |
| `expandClick` | A custom event emitted when the accordion item control is activated. | `CustomEvent<any>` |

## Slots

| Slot | Description |
| --- | --- |
|  | Hidden/revealed content is placed in the default slot. |
| `"cbp-expand-label"` | Optionally the component label/heading may be slotted via named slot if it contains markup rather than plain text. |
