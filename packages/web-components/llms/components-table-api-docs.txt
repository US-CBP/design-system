# cbp-table

## Overview

The Table component is a wrapper component encapsulating design system styles for semantic HTML tables as well as applying progressive enhancements to the contained table.

## Properties

| Property | Attribute | Description | Type | Default |
| --- | --- | --- | --- | --- |
| `columnHover` | `column-hover` | Specifies whether a hover effect is applied to columns when the column header is hovered. This feature is opt-in. | `boolean` | `undefined` |
| `context` | `context` | Specifies the context of the component as it applies to the visual design and whether it inverts when light/dark mode is toggled. Default behavior is "light-inverts" and does not have to be specified. | `"dark-always" | "dark-inverts" | "light-always" | "light-inverts"` | `undefined` |
| `hover` | `hover` | Specifies whether the mouse cursor highlights the table row or cell on hover. Defaults to "row". | `"cell" | "row"` | `'row'` |
| `overflow` | `overflow` | Specifies whether the table is striped, designating whether the colored rows are the odd or even rows (CBP DS standard is even when used). | `"linearize" | "scroll"` | `'scroll'` |
| `striped` | `striped` | Specifies whether the table is striped, designating whether the colored rows are the odd or even rows (CBP DS standard is even when used). | `"even" | "odd"` | `undefined` |
| `sx` | `sx` | Supports adding inline styles as an object | `any` | `{}` |

## Events

| Event | Description | Type |
| --- | --- | --- |
| `tableSort` | An event emitted when the table is sorted via user interaction activating a table header control. | `CustomEvent<any>` |

## Methods

### `doSort(column: number, e?: any) => Promise<void>`

Updates the UI statefullness (`aria-pressed`, `aria-sort`, and visual arrow icon) and emits a custom event to hook up to application logic for the actual sorting

## Slots

| Slot | Description |
| --- | --- |
|  | The semantic table HTML is placed within the default slot. |
| `"cbp-table-live-region"` | For complex tables with many controls and/or pagination, the state of the data may be quantified and described accessibly via an `aria-live` region, which is hidden from view. E.g., Filtered by the term "test", ordered by Column 1 ascending, displaying records 100-200 of 1234. |
| `"cbp-table-toolbar"` | Any sort of filters or table controls may be slotted within this named slot. |
