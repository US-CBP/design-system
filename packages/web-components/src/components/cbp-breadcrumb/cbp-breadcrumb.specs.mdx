# cbp-breadcrumb

## Purpose

* Breadcrumb component exist to give users a key indicator of where they are within an application when the user happens to be deeper
within the site’s architecture. It should only be used on pages that are at least a C level page (A being the homepage, B a child of 
the homepage, C a child of the child page). the Breadcrumb is primarily made using the cbp-button & cbp-link, as such please also 
review the documentation for those components as well.

## Functional Requirements

* Breadcrumb requires an href for the sites 'home page' and a user specified seires of cbp-links
