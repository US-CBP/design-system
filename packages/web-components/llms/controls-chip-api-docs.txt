# cbp-chip

## Overview

The Chip component acts like an interactive version of the Tag and is typically used for selecting or filtering.

## Properties

| Property | Attribute | Description | Type | Default |
| --- | --- | --- | --- | --- |
| `context` | `context` | Specifies the context of the component as it applies to the visual design and whether it inverts when light/dark mode is toggled. Default behavior is "light-inverts" and does not have to be specified. | `"dark-always" | "dark-inverts" | "light-always" | "light-inverts"` | `undefined` |
| `disabled` | `disabled` | Marks the rendered button/link in a disabled state when specified. | `boolean` | `undefined` |
| `name` | `name` | Specifies the `name` attribute of the rendered button | `string` | `undefined` |
| `pressed` | `pressed` | Specifies the pressed state of the button and `aria-pressed` attribute of the rendered button | `boolean` | `false` |
| `sx` | `sx` | Supports adding inline styles as an object | `any` | `{}` |
| `value` | `value` | Specifies the `value` attribute of the rendered button | `string` | `undefined` |

## Events

| Event | Description | Type |
| --- | --- | --- |
| `chipClick` | A custom event emitted when the chip is activated/toggled. | `CustomEvent<any>` |

## Slots

| Slot | Description |
| --- | --- |
|  | The default slot defines the chip's label. |
| `"cbp-chip-icon"` | Optionally slot a custom icon for the default state (will still show the x for removal when pressed). |
