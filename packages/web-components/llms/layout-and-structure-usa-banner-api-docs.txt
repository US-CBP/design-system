# cbp-usa-banner

## Overview

The "USA Banner" is similar to the U.S. Web Design System "banner" component, intended to establish trust as a common identifier on public-facing government sites.

## Properties

| Property | Attribute | Description | Type | Default |
| --- | --- | --- | --- | --- |
| `open` | `open` | Specifies that the banner is open. Primarily used for internal component logic. | `boolean` | `false` |

## CSS Custom Properties

| Name | Description |
| --- | --- |
| `--cbp-usa-banner-background-color` | var(--cbp-color-gray-cool-90); |
| `--cbp-usa-banner-color` | var(--cbp-color-text-lightest); |
