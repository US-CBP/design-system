# cbp-form-field

## Overview

The Form Field component represents a generic, reusable pattern for form fields of all types, displaying the label and form control, along with optional descriptive text and error state in a consistent and accessible manner.

## Properties

| Property | Attribute | Description | Type | Default |
| --- | --- | --- | --- | --- |
| `context` | `context` | Specifies the context of the component as it applies to the visual design and whether it inverts when light/dark mode is toggled. Default behavior is "light-inverts" and does not have to be specified. | `"dark-always" | "dark-inverts" | "light-always" | "light-inverts"` | `undefined` |
| `description` | `description` | Provide additional details about the field, including whether it's required, which is applied to the form field via `aria-describedby`. | `string` | `undefined` |
| `disabled` | `disabled` | Specifies that the field is disabled; sets all form fields and button controls as disabled. | `boolean` | `undefined` |
| `error` | `error` | Specifies that the field has an error (and sets aria-invalid accordingly). | `boolean` | `undefined` |
| `errorMessages` | `error-messages` | Specifies the error message(s) to replace the description text while in an error state. | `any` | `undefined` |
| `fieldId` | `field-id` | Optionally specify the ID of the field here, which is used to generate related pattern node IDs and associate everything for accessibility | `string` | `createNamespaceKey('cbp-formfield')` |
| `group` | `group` | Specifies that this form field represents a group of (slotted) inputs, such as a radio list, checklist, or related inputs in a compound pattern. | `boolean` | `undefined` |
| `label` | `label` | Provide a visible/accessible label for the form field/group. | `string` | `undefined` |
| `readonly` | `readonly` | Specifies that the field is readonly; sets all form fields as readonly and related button controls to disabled. | `boolean` | `undefined` |
| `sx` | `sx` | Supports adding inline styles as an object | `any` | `{}` |

## Events

| Event | Description | Type |
| --- | --- | --- |
| `valueChange` | A custom event emitted when the the nested input is changed by user interaction. | `CustomEvent<any>` |

## Slots

| Slot | Description |
| --- | --- |
|  | the default slot holds the form control(s)/input(s). |
| `"cbp-form-field-description"` | An optional slot for descriptions containing markup. |
| `"cbp-form-field-label"` | An optional slot for labels containing markup. |
