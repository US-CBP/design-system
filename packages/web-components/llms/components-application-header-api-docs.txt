# cbp-app-header

## Properties

| Property | Attribute | Description | Type | Default |
| --- | --- | --- | --- | --- |
| `search` | `search` | Specifies if there will be a slotted input for global search | `boolean` | `undefined` |
| `searchAction` | `search-action` | Specifies the action attribute for the search form | `string` | `undefined` |
| `searchMethod` | `search-method` | Specifies the method attribute for the search form | `string` | `undefined` |
| `subnavDrawerId` | `subnav-drawer-id` | Specifies the id of the drawer to be launched | `string` | `undefined` |

## Events

| Event | Description | Type |
| --- | --- | --- |
| `searchInput` | A custom event emitted in accordance with the native input's onInput event. | `CustomEvent<any>` |
| `searchSubmit` | A custom event emitted in accordance with the native search form's submit event. | `CustomEvent<any>` |

## Methods

### `closeSearch() => Promise<void>`

A public method to close/hide the search form in the application header.

#### Returns

Type: `Promise<void>`

### `openSearch() => Promise<void>`

A public method to show the search form in the application header.

#### Returns

Type: `Promise<void>`

## Slots

| Slot | Description |
| --- | --- |
|  | The default slot usually contains only `cbp-nav-item` tags, but other content may also be included. |
|  | cbp-home - The link to the home page containing the Application Name as link text should be placed within this named slot for the intended visual treatment. |
|  | cbp-app-header-extras - Optional extra buttons/links that are right-aligned may be slotted within the app header but outside of the `nav` landmark. |

# cbp-nav-item

## Overview

The Nav Item component wraps each individual control (link or button) within the App Header.

## Properties

| Property | Attribute | Description | Type | Default |
| --- | --- | --- | --- | --- |
| `current` | `current` | Specifies whether this is the Nav Item that represents the current page. Only one item per set should be marked as current. | `boolean` | `undefined` |
| `name` | `name` | Specifies a name used to associated Nav Items with Subnav Items. | `string` | `undefined` |
| `sx` | `sx` | Supports adding inline styles as an object. | `any` | `{}` |

## Events

| Event | Description | Type |
| --- | --- | --- |
| `navItemClick` |  | `CustomEvent<any>` |

## Slots

| Slot | Description |
| --- | --- |
|  | Any form of control may be slotted in the default slot (a link, button, link component, button component, component-based Router, etc.). But any components should render a semantic anchor or button element. |
