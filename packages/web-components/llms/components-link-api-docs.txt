# cbp-link

## Overview

The cbp-link component is used to render an anchor or provide consistent styling for a slotted anchor.

## Properties

| Property | Attribute | Description | Type | Default |
| --- | --- | --- | --- | --- |
| `accessibilityText` | `accessibility-text` | Specifies an accessible label for the rendered anchor via `aria-label`. | `string` | `undefined` |
| `context` | `context` | Specifies the context of the component as it applies to the visual design and whether it inverts when light/dark mode is toggled. Default behavior is "light-inverts" and does not have to be specified. | `"dark-always" | "dark-inverts" | "light-always" | "light-inverts"` | `undefined` |
| `disabled` | `disabled` | Specifies whether the the rendered anchor is "disabled". Creating disabled anchors may introduce accessibility concerns - use with caution. | `boolean` | `undefined` |
| `download` | `download` | Specifies the `download` boolean attribute of the rendered anchor. | `boolean` | `undefined` |
| `href` | `href` | Specifies the `href` of the rendered anchor. | `string` | `undefined` |
| `language` | `language` | Specifies the `lang` attribute of the rendered anchor. | `string` | `undefined` |
| `rel` | `rel` | Specifies the `rel` attribute of the rendered anchor. | `string` | `undefined` |
| `shortcutKey` | `shortcut-key` | Defines an `accesskey` attribute of the rendered anchor. | `string` | `undefined` |
| `sx` | `sx` | Supports adding inline styles as an object | `any` | `{}` |
| `target` | `target` | Specifies the `target` attribute of the rendered anchor. | `string` | `undefined` |

## Events

| Event | Description | Type |
| --- | --- | --- |
| `linkClick` | A custom event emitted with the anchor is activated/clicked. | `CustomEvent<any>` |

## Slots

| Slot | Description |
| --- | --- |
|  | the default slot represents the linked content, which may include markup, for the rendered anchor tag. |
| `"cbp-link-custom"` | Custom anchors may be slotted via named-slot, which prevents the web component from rendering its own anchor tag. |
