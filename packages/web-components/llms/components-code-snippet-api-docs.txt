# cbp-code-snippet

## Overview

The Code Snippet component is used to display code in a readable format and facilitate copying it.

## Properties

| Property | Attribute | Description | Type | Default |
| --- | --- | --- | --- | --- |
| `context` | `context` | Specifies the context of the component as it applies to the visual design and whether it inverts when light/dark mode is toggled. Default behavior is "light-inverts" and does not have to be specified. | `"dark-always" | "dark-inverts" | "light-always" | "light-inverts"` | `undefined` |
| `height` | `height` | Specifies the height (in CSS units) for a multiple line block variant while not expanded. | `string` | `undefined` |
| `sx` | `sx` | Supports adding inline styles as an object | `any` | `{}` |
| `variant` | `variant` | Specifies inline or block layouts of the code snippet. Defaults to inline. | `"block" | "inline"` | `'inline'` |

## Events

| Event | Description | Type |
| --- | --- | --- |
| `copyTextClick` | Emits a custom event when the "Copy" button is activated, copying the code to the clipboard. | `CustomEvent<any>` |
| `toggleShowAllClick` | Emits a custom event when the the "Show More/Less" control is activated (for code blocks overflowing the specified height). | `CustomEvent<any>` |

## Slots

| Slot | Description |
| --- | --- |
|  | Raw, unescaped code is slotted in the default slot and escaped for display purposes. |
