# cbp-menu

## Overview

A Menu contains additional actions in the form of links or buttons, which can be shown by activating a control.

## Properties

| Property | Attribute | Description | Type | Default |
| --- | --- | --- | --- | --- |
| `accessibilityText` | `accessibility-text` | Creates an accessible label for the menu control. | `string` | `undefined` |
| `context` | `context` | Specifies the context of the component as it applies to the visual design and whether it inverts when light/dark mode is toggled. Default behavior is "light-inverts" and does not have to be specified. | `"dark-always" | "dark-inverts" | "light-always" | "light-inverts"` | `undefined` |
| `open` | `open` | When set, specifies that the menu is open. | `boolean` | `false` |
| `position` | `position` | Specifies the position of the menu. Defaults to "bottom-start". | `"bottom-end" | "bottom-start" | "top-end" | "top-start"` | `'bottom-start'` |
| `sx` | `sx` | Supports adding inline styles as an object | `any` | `{}` |
| `uid` | `uid` | Specifies a unique `ID` for the menu, used to wire up the controls and accessibility features. | `string` | `createNamespaceKey('cbp-menu')` |

## Events

| Event | Description | Type |
| --- | --- | --- |
| `toggleMenu` | A custom event fired when the menu is opened or closed. | `CustomEvent<any>` |

## Methods

### `closeMenu() => Promise<void>`

A public method for closing the menu.

#### Returns

Type: `Promise<void>`

### `openMenu() => Promise<void>`

A public method for opening the menu.

#### Returns

Type: `Promise<void>`

## Slots

| Slot | Description |
| --- | --- |
|  | Both the menu control and the menu items are slotted in the default slot. (The menu items are auto-slotting into their proper place). |

## CSS Custom Properties

| Name | Description |
| --- | --- |
| `--cbp-menu-color-bg` | var(--cbp-color-gray-cool-80); |
| `--cbp-menu-color-bg-dark` | var(--cbp-color-gray-cool-5); |
| `--cbp-menu-gap` | var(--cbp-space-3x); |

# cbp-menu-item

## Overview

The Menu Item component wraps each individual control (link or button) within the menu.

## Properties

| Property | Attribute | Description | Type | Default |
| --- | --- | --- | --- | --- |
| `color` | `color` | Specifies a color variant for the menu item. Currently the only supported variant is "danger". | `"danger"` | `undefined` |
| `indentLevel` | `indent-level` | Specifies an indent level to represent hierarchical items. Defaults to zero. | `number` | `0` |

## Slots

| Slot | Description |
| --- | --- |
|  | Any form of control may be slotted in the default slot (a link, button, link component, button component, component-based Router, etc.). But any components should render a semantic anchor or button element. |
