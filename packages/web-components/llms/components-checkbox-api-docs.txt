# cbp-checkbox

## Overview

The Checkbox component wraps the slotted native form control (`input type="checkbox"`) and label text, providing cross-browser styling according to the design system specifications.

## Properties

| Property | Attribute | Description | Type | Default |
| --- | --- | --- | --- | --- |
| `checked` | `checked` | Marks the checkbox as checked by default when specified. | `boolean` | `undefined` |
| `context` | `context` | Specifies the context of the component as it applies to the visual design and whether it inverts when light/dark mode is toggled. Default behavior is "light-inverts" and does not have to be specified. | `"dark-always" | "dark-inverts" | "light-always" | "light-inverts"` | `undefined` |
| `disabled` | `disabled` | Marks the checkbox in a disabled state when specified. | `boolean` | `undefined` |
| `fieldId` | `field-id` | Optionally specify the ID of the checkbox input here, which is used to generate related pattern node IDs and associate everything for accessibility | `string` | `createNamespaceKey('cbp-checkbox')` |
| `indeterminate` | `indeterminate` | Marks the checkbox as checked by default when specified. | `boolean` | `undefined` |
| `name` | `name` | The `name` attribute of the checkbox, which is passed as part of formData (as a key) only when the checkbox is checked. | `string` | `undefined` |
| `sx` | `sx` | Supports adding inline styles as an object | `any` | `{}` |
| `value` | `value` | Optionally set the `value` attribute of the checkbox at the component level. Not needed if the slotted checkbox has a value. | `string` | `undefined` |

## Events

| Event | Description | Type |
| --- | --- | --- |
| `stateChanged` | A custom event emitted when the checked state changes due to user interaction. | `CustomEvent<any>` |

## Methods

### `reset() => Promise<void>`

A custom method to reset the Checkbox component to its initial state and value since it does not update properly on a native form reset when the checked state is set via the component property. This method may be called manually, but is automatically called on form reset when using the `cbp-form` component.

#### Returns

Type: `Promise<void>`

## Slots

| Slot | Description |
| --- | --- |
|  | the checkbox control and label text are placed in the default slot, both of which are rendered inside of the `label` element. The label should not include excessively long descriptive text. |
