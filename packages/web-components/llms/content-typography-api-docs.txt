# cbp-typography

## Overview

The Typography component encapsulates predefined styles for different kinds of text that makes up a website, merging design language with CSS and HTML implementations.

## Properties

| Property | Attribute | Description | Type | Default |
| --- | --- | --- | --- | --- |
| `context` | `context` | Specifies the context of the component as it applies to the visual design and whether it inverts when light/dark mode is toggled. Default behavior is "light-inverts" and does not have to be specified. | `"dark-always" | "dark-inverts" | "light-always" | "light-inverts"` | `undefined` |
| `divider` | `divider` | Specifies whether the text contains visual treatments that act as a divider. | `"fill" | "underline"` | `undefined` |
| `sx` | `sx` | Supports adding inline styles as an object | `any` | `{}` |
| `tag` | `tag` | Specifies the semantic tag to be rendered. | `"code" | "div" | "h1" | "h2" | "h3" | "h4" | "h5" | "h6" | "p" | "pre" | "span"` | `"span"` |
| `variant` | `variant` | Specifies the visual style of the text regardless of the semantic tag. | `"body-text" | "heading-dialog" | "heading-lg" | "heading-md" | "heading-sm" | "heading-xl" | "heading-xs" | "heading-xxl" | "masthead-1" | "masthead-2" | "subhead"` | `undefined` |
