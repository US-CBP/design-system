# cbp-floating-action

## Purpose

The Floating Action is a container component to have buttons, links, or other actionable components that need to be accessible to the user above all other content

## Functional Requirements

* The floating action component is a container used to place the slotted content.
* Component allows for positioned anywhere relative to the viewport.
* A box-shadow will be applied to the `button` tag of any slotted cbp-buttons.

## Technical Specifications
 

### User Interactions

* The floating action component is a container, any user interactions would be dependent on the slotted component.

### Responsiveness

* Tab order for content of the floating action will be affected by placement in source document.
* All other accessibility concerns should be managed by the slotted elements.

### Accessibility

* Suggested to use `--cbp-responsive-spacing-outer` for horizontal positioning via component props to have floating action follow responsive breakpoints of page.
* All other responsive behavior to be implemented by the application logic or css.

### Additional Notes and Considerations

* While floating action will accept any number of slotted elements the visual spec is intended to house 2 elements at most.
* Recommended to use a cbp-flex to visualy orient if there are multiple slotted items to go inside the floating action.
