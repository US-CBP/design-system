# cbp-multicol

## Overview

The Multicol component is a wrapper that invokes a CSS Multi-column layout context, ideal for using with semantic lists and checklists/radio lists.

## Properties

| Property | Attribute | Description | Type | Default |
| --- | --- | --- | --- | --- |
| `columns` | `columns` | Specifies the maximum number of columns | `number` | `undefined` |
| `gap` | `gap` | Specifies the gap between columns in CSS units (preferably relative units such as `rem`). | `string` | `undefined` |
| `nobreak` | `nobreak` | Specifies that children shall not be broken to spread contents across columns (using `break-inside: avoid` CSS). | `boolean` | `undefined` |
| `rule` | `rule` | Specifies the rule separating each column (syntax is similar to CSS borders, including a width, style, and color). | `string` | `undefined` |
| `sx` | `sx` | Supports adding inline styles as an object | `any` | `{}` |
| `width` | `width` | Specifies the minimum column width in CSS units (preferably relative units such as `rem`). The column width may affect how many columns are actually used based upon available space. | `string` | `undefined` |

## Slots

| Slot | Description |
| --- | --- |
|  | The default slot contains any content or children to be arranged in a multi-column layout. |
