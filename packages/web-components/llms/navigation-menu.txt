# Navigation/Menu

## Examples


### Actions Menu

```tsx
({
  position,
  items,
  context,
  sx
}) => {
  return ` 
    <cbp-menu
      uid="menuId"
      ${position ? `position="${position}"` : ''}
      ${context ? `context="${context}"` : ''}
      ${sx ? `sx='${JSON.stringify(sx)}'` : ''}
    >

      <cbp-button
        fill="outline"
        color="secondary"
        variant="square"
        accessibility-text="Actions"
        target-prop="open"
        controls="menuId"
      >
        <cbp-icon name="ellipsis-vertical"></cbp-icon>
      </cbp-button>

      ${generateMenuItem(items)}
      
    </cbp-menu>
  `;
}
```
