# Components/Multicol

## Examples


### Multicol

```tsx
({
  content,
  columns,
  width,
  gap,
  rule,
  nobreak,
  sx
}) => {
  return `
      <cbp-multicol
        ${columns ? `columns="${columns}"` : ''}
        ${width ? `width="${width}"` : ''}
        ${gap ? `gap="${gap}"` : ''}
        ${rule ? `rule="${rule}"` : ''}
        ${nobreak ? `nobreak` : ''}
        ${sx ? `sx='${JSON.stringify(sx)}'` : ''}
        role="list"
      >
        ${createChildren(content)}
      </cbp-multicol>
  `;
}
```
