# Layout and Structure/Skip Navigation Link

## Examples


### Skip Navigation Link

```tsx
({
  text,
  targetId,
  shortcutKey,
  sx
}) => {
  return ` 
    <cbp-skip-nav
      ${targetId ? `target-id="${targetId}"` : ''}
      ${shortcutKey ? `shortcut-key="${shortcutKey}"` : ''}
      ${sx ? `sx='${JSON.stringify(sx)}'` : ''}
    >${text ? text : ''}</cbp-skip-nav>
  `;
}
```
