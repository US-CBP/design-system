# cbp-tabs

## Overview

Tabs are a common UI pattern of progressive disclosure mimicking the real world paradigm of tabbed folders, each with a label and containing their own set of contents. Tabs allow the user to navigate multiple views without leaving the page. This component wraps individual `cbp-tab` components.

## Properties

| Property | Attribute | Description | Type | Default |
| --- | --- | --- | --- | --- |
| `accessibilityText` | `accessibility-text` | The accessible label of the tablist. Required unless `aria-labelledby` is specified on the host tag directly. | `string` | `undefined` |
| `context` | `context` | Specifies the context of the component as it applies to the visual design and whether it inverts when light/dark mode is toggled. Default behavior is "light-inverts" and does not have to be specified. | `"dark-always" | "dark-inverts" | "light-always" | "light-inverts"` | `undefined` |
| `sx` | `sx` | Supports adding inline styles as an object | `any` | `{}` |

## Slots

| Slot | Description |
| --- | --- |
|  | Only `cbp-tab` components shall be slotted within the default slot. |

# cbp-tab

## Overview

The Tab component represents an individual tab control within a tab set.

## Properties

| Property | Attribute | Description | Type | Default |
| --- | --- | --- | --- | --- |
| `accessibilityText` | `accessibility-text` | For tabs without a visible text label (e.g., icon tabs) or a label that is insufficiently unique/descriptive, you may provide accessibility text, which is rendered as an `aria-label` on the tab control (button element). | `string` | `undefined` |
| `color` | `color` | An optional color variant. | `"danger"` | `undefined` |
| `name` _(required)_ | `name` | An `ID`-conformant unique name of the tab; This value should match the corresponding cbp-tab-panel name and links the two together. | `string` | `undefined` |
| `selected` | `selected` | Specifies whether this is the selected tab. Only one tab per tabset should be marked as selected. | `boolean` | `undefined` |
| `sx` | `sx` | Supports adding inline styles as an object | `any` | `{}` |

## Events

| Event | Description | Type |
| --- | --- | --- |
| `tabClicked` | Emits a custom even containing an object that describes the tab that was activated. | `CustomEvent<any>` |
| `tabLoaded` | Emits an event when the tab has been fully loaded for registration with the parent tabset. | `CustomEvent<any>` |

## Slots

| Slot | Description |
| --- | --- |
|  | The default slot holds the tab's label (rendered as a button label), which may include text as well as icons, badges, and tags. |

# cbp-tab-panel

## Overview

The Tab Panel component is a wrapper representing a tabpanel role and containing the content to be progressively disclosed.

## Properties

| Property | Attribute | Description | Type | Default |
| --- | --- | --- | --- | --- |
| `name` _(required)_ | `name` | An `ID`-conformant unique name of the tab-panel, applied as an `id` on this tab panel; This value should match the corresponding cbp-tab name and links the two together. | `string` | `undefined` |
| `selected` | `selected` | Specifies if this is the tab panel corresponding to the selected tab and currently visible. This property is managed by the parent cbp-tabs component and does not need to be set manually. | `boolean` | `undefined` |
| `sx` | `sx` | Supports adding inline styles as an object | `any` | `{}` |

## Slots

| Slot | Description |
| --- | --- |
|  | The default slot holds the contents of a tab panel, which may include any form of text, markup, and media elements. |
