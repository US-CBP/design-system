# cbp-pagination

## Overview

The Pagination component presents a common UI pattern for displaying data sets broken up into smaller, more consumable (and performant) chunks or "pages."

## Properties

| Property | Attribute | Description | Type | Default |
| --- | --- | --- | --- | --- |
| `context` | `context` | Specifies the context of the component as it applies to the visual design and whether it inverts when light/dark mode is toggled. Default behavior is "light-inverts" and does not have to be specified. | `"dark-always" | "dark-inverts" | "light-always" | "light-inverts"` | `undefined` |
| `maxPages` | `max-pages` | Specifies the current maximum number of pages allowed. This property should be used for extremely large data sets that have the potential to returns hundreds or thousands of pages. | `number` | `undefined` |
| `page` | `page` | Specifies the current page being viewed. Defaults to 1. | `number` | `1` |
| `pageSize` | `page-size` | Specifies the number of items to show per page. Accepts any number or "all". Defaults to 10. | `"all" | number` | `10` |
| `records` | `records` | Specifies the number of records in the entire data set (complete or filtered) to be paginated. | `number` | `0` |
| `sx` | `sx` | Supports adding inline styles as an object | `any` | `{}` |

## Events

| Event | Description | Type |
| --- | --- | --- |
| `paginationChange` | A custom event emitted when the click event occurs for either a rendered button or anchor/link. | `CustomEvent<any>` |

## Slots

| Slot | Description |
| --- | --- |
|  | The default slot positions specified content between the "showing items" text and page controls. This slot should rarely be used. |
| `"cbp-pagination-items-per-page"` | Slot a `cbp-dropdown` here with numeric values (or "All") defining the options for page size. |
| `"cbp-pagination-pages"` | Slot an empty `cbp-dropdown` here with next/previous controls for the page selection. The Pagination component will manage the items within this dropdown. |

## CSS Custom Properties
