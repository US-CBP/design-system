# cbp-dropdown

## Overview

The Dropdown component offers an alternative to the native select element that can be fully styled and support additional variants, such as a multi-select and/or combobox.

## Properties

| Property | Attribute | Description | Type | Default |
| --- | --- | --- | --- | --- |
| `async` | `async` | Indicates that the filtering will be performed by asynchronous calls (handled by application logic). | `boolean` | `false` |
| `context` | `context` | Specifies the context of the component as it applies to the visual design and whether it inverts when light/dark mode is toggled. Default behavior is "light-inverts" and does not have to be specified. | `"dark-always" | "dark-inverts" | "light-always" | "light-inverts"` | `undefined` |
| `create` | `create` | Specifies that when an exact match is not found for a search string (for combobox functionality), an option to create a new item is presented. | `boolean` | `undefined` |
| `debug` | `debug` | Turns on debug mode, since the dropdown is complex and has complex integration concerns. (This prop is temporary and will be removed) | `boolean` | `false` |
| `disabled` | `disabled` | Specifies that the field is disabled. Primarily controlled by the parent `cbp-form-field` component. | `boolean` | `false` |
| `error` | `error` | Specifies that the field has an error (and sets aria-invalid accordingly). Primarily controlled by the parent `cbp-form-field` component. | `boolean` | `false` |
| `fieldId` | `field-id` | Optionally specify the ID of the visible control here, which is used to generate related pattern node IDs and associate everything for accessibility. | `string` | `createNamespaceKey('cbp-dropdown')` |
| `filter` | `filter` | Specifies whether the dropdown accepts key presses to filter results, enabling combobox functionality. | `boolean` | `false` |
| `items` | `items` | A JSON object (or stringified JSON) containing an array of labels, values, and optionally selected status. Labels may contain markup as needed, but in such cases, a value should always be specified explicitly. The expected format is [{"label":"string","value":"string","selected":"boolean (optional"}, ...] | `object | string` | `undefined` |
| `minimumInputLength` | `minimum-input-length` | Specifies the number of characters need to emit an event to make an API call and return filtered results. This property is only used when filter=true AND async=true. | `number` | `1` |
| `multiple` | `multiple` | Specifies whether multiple selections are supported, in which case checkboxes shall be slotted in accordance with the design system specified pattern. Defaults to false, which renders a single-select dropdown. | `boolean` | `false` |
| `name` | `name` | Specifies the name of the (hidden) form field | `string` | `this.fieldId` |
| `open` | `open` | Specifies whether the dropdown menu is open/visible. | `boolean` | `false` |
| `placeholder` | `placeholder` | Represents placeholder text on the dropdown control, displayed in a distinctive style from the selected item. Defaults to "Choose Item". Has no effect on multi-selects, as the component manages this text. | `string` | `'Choose Item'` |
| `readonly` | `readonly` | Specifies that the field is readonly. Primarily controlled by the parent `cbp-form-field` component. | `boolean` | `false` |
| `selectedLabel` | `selected-label` | Specifies the visible label on the dropdown control of the selected item. Primarily updated dynamically by the component. | `string` | `undefined` |
| `sx` | `sx` | Supports adding inline styles (to the host) as an object. This property is not reactive. | `any` | `{}` |
| `value` | `value` | Specifies the value of the hidden input holding the value (or barring one, the text label) of the selected item. Primarily updated dynamically by the component. | `any` | `''` |

## Events

| Event | Description | Type |
| --- | --- | --- |
| `createItem` | A custom event that is fired when the "create item" option is clicked. | `CustomEvent<any>` |
| `filterKeypress` | A custom event that is fired when a key is pressed while filtering a combobox. | `CustomEvent<any>` |
| `populateCombobox` | A custom event emitted for asynchronous comboboxes (`async=true` and `filter=true`) and the search string meets the `minimumInputLength` requirement. This event can be listened for and the `items` (JSON) updated via application logic/service call. | `CustomEvent<any>` |
| `valueChange` | A custom event emitted when the a selection is made in the dropdown. | `CustomEvent<any>` |

## Methods

### `clearSelections(e?: any) => Promise<void>`

A public method to clear all selected items in a dropdown (single or multi-select). Emits the valueChange event afterward.

#### Parameters

| Name | Type | Description |
| --- | --- | --- |
| `e` | `any` |  |

#### Returns

Type: `Promise<void>`

### `reset() => Promise<void>`

A custom method to reset the Dropdown component to its initial state and value since it does not update properly on a native form reset. This method may be called manually, but is automatically called on form reset when using the `cbp-form` component.

#### Returns

Type: `Promise<void>`

## Slots

| Slot | Description |
| --- | --- |
|  | Only Dropdown Items should be placed in the default slot. They get auto-slotted into 'cbp-dropdown-items' behind the scenes. |
| `"cbp-dropdown-attached-button-end"` | Allows for an optional button control to be slotted as an overlay at the end of the dropdown (such as a "next" button). |
| `"cbp-dropdown-attached-button-start"` | Allows for an optional button control to be slotted as an overlay at the start of the dropdown (such as a "previous" button). |
| `"cbp-dropdown-items"` | Dropdown items are auto-slotted here. Not need to specify this named slot. |

# cbp-dropdown-item

## Overview

The Dropdown Item represents an individual option for the Dropdown, similar to an option in a native `select` but with more flexibility.

## Properties

| Property | Attribute | Description | Type | Default |
| --- | --- | --- | --- | --- |
| `current` | `current` | For Internal Use: Specifies the current item (referenced by `aria-activedescendant`) while using keyboard navigation. | `boolean` | `undefined` |
| `disabled` | `disabled` |  | `boolean` | `undefined` |
| `itemId` | `item-id` | Optionally specify the ID of each dropdown item, which is used by the parent dropdown to associate `aria-activedescendant`. If no `itemId` is specified, one will be automatically generated. | `string` | `createNamespaceKey('cbp-dropdown-item')` |
| `selected` | `selected` | Specifies if an item is selected | `boolean` | `undefined` |
| `value` | `value` | Specifies an optional value to be passed in the FormData instead of the display text/label. | `string` | `undefined` |

## Events

| Event | Description | Type |
| --- | --- | --- |
| `dropdownItemClick` | Internal use: A custom event emitted when a dropdown item is clicked/activated and is handled by the parent dropdown, also resulting in a `valueChange` event emitted from the dropdown component. | `CustomEvent<any>` |

## Slots

| Slot | Description |
| --- | --- |
|  | The Dropdown Item's label or content goes in the default slot; for multi-select dropdowns, this includes the checkbox component and slotted native `input type="checkbox"` and label. |
