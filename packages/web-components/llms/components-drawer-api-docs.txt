# cbp-drawer

## Overview

The Drawer is a container that may be hidden and revealed, sliding in from either side of the viewport, containing application-defined contents. The Drawer may optionally be rendered in the flow of the page at larger screen sizes.

## Properties

| Property | Attribute | Description | Type | Default |
| --- | --- | --- | --- | --- |
| `accessibilityText` | `accessibility-text` | Creates an accessible label for the drawer (dialog). | `string` | `undefined` |
| `context` | `context` | Specifies the context of the component as it applies to the visual design and whether it inverts when light/dark mode is toggled. Default behavior is "light-inverts" and does not have to be specified. | `"dark-always" | "dark-inverts" | "light-always" | "light-inverts"` | `undefined` |
| `open` | `open` | When set, specifies that the drawer is open | `boolean` | `undefined` |
| `persistAt` | `persist-at` | Specifies a valid CSS media query (preferably using relative units), when met will hide the wrapped content using display: none. E.g., `min-width:64em` | `string` | `undefined` |
| `position` | `position` | Specifies the position of the drawer (left or right) | `"left" | "right"` | `'left'` |
| `sx` | `sx` | Supports adding inline styles as an object | `any` | `{}` |
| `uid` | `uid` | Specifies a unique `ID` for the drawer, used to wire up the controls and accessibility features. | `string` | `undefined` |
