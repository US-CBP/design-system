# Components/Typography

## Examples


### Typography

```tsx
({
  text,
  tag,
  variant,
  divider,
  context,
  sx
}) => {
  return ` 
      <cbp-typography
        ${tag ? `tag=${tag}` : ''}
        ${variant != undefined ? `variant=${variant}` : ''}
        ${divider != 'none' ? `divider=${divider}` : ''}
        ${context && context != 'light-inverts' ? `context=${context}` : ''}
        ${sx ? `sx='${JSON.stringify(sx)}'` : ''}
      >
        ${text}
      </cbp-typography>
    `;
}
```
