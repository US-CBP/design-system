# cbp-radio

## Overview

The Radio component wraps the slotted native form control (`input type="radio"`) and label text, providing cross-browser styling.

## Properties

| Property | Attribute | Description | Type | Default |
| --- | --- | --- | --- | --- |
| `checked` | `checked` | Marks the radio button as checked by default when specified. | `boolean` | `undefined` |
| `context` | `context` | Specifies the context of the component as it applies to the visual design and whether it inverts when light/dark mode is toggled. Default behavior is "light-inverts" and does not have to be specified. | `"dark-always" | "dark-inverts" | "light-always" | "light-inverts"` | `undefined` |
| `disabled` | `disabled` | Marks the radio button in a disabled state when specified. | `boolean` | `undefined` |
| `fieldId` | `field-id` | Optionally specify the ID of the checkbox input here, which is used to generate related pattern node IDs and associate everything for accessibility | `string` | `createNamespaceKey('cbp-radio')` |
| `name` | `name` | The `name` attribute of the radio button, which is passed as part of formData (as a key) only when the radio button is checked. | `string` | `undefined` |
| `sx` | `sx` | Supports adding inline styles as an object | `any` | `{}` |
| `value` | `value` | Optionally set the `value` attribute of the radio button at the component level. Not needed if the slotted radio button has a value. | `string` | `undefined` |

## Events

| Event | Description | Type |
| --- | --- | --- |
| `stateChanged` | A custom event emitted when the click event occurs for either a rendered button or anchor/link. | `CustomEvent<any>` |

## Methods

### `reset() => Promise<void>`

A custom method to reset the Radio component to its initial state and value since it does not update properly on a native form reset when the checked state is set via the component property. This method may be called manually, but is automatically called on form reset when using the `cbp-form` component.

#### Returns

Type: `Promise<void>`

## Slots

| Slot | Description |
| --- | --- |
|  | The radio control and label text goes in the default slot, both of which are placed inside of the `label` element. The label should not include excessively long descriptive text. |
