# cbp-loader

## Overview

The Loader is used as a visual indicator of progress during waiting periods.

## Properties

| Property | Attribute | Description | Type | Default |
| --- | --- | --- | --- | --- |
| `context` | `context` | Specifies the context of the component as it applies to the visual design and whether it inverts when light/dark mode is toggled. Default behavior is "light-inverts" and does not have to be specified. | `"dark-always" | "dark-inverts" | "light-always" | "light-inverts"` | `undefined` |
| `determinate` | `determinate` | Defines if the loader will be in determinate/indeterminate, if true loader will display the current value out of max value | `boolean` | `false` |
| `error` | `error` | Used to set the loader to the 'error' state of the loader | `boolean` | `undefined` |
| `max` | `max` | Used in deternminate mode to display the max value of loaded content | `number` | `100` |
| `orientation` | `orientation` | Used to set the text orientation for the circular determinate loader's description | `"horizontal" | "vertical"` | `'horizontal'` |
| `progressId` | `progress-id` | Specifies a unique `ID` for the loader, used to wire up the controls and accessibility features. | `string` | `createNamespaceKey('cbp-loader')` |
| `size` | `size` | Defines the size of the loader render, default value of large | `"large" | "small"` | `"large"` |
| `success` | `success` | Used to set the loader to the 'success' state of the loader | `boolean` | `undefined` |
| `sx` | `sx` | Supports adding inline styles as an object | `any` | `{}` |
| `value` | `value` | Used in deternminate mode to display the current value of loaded content | `number` | `0` |
| `variant` | `variant` | Defines if the loader will be in displayed as a circular or linear variant | `"circular" | "linear"` | `undefined` |
