# cbp-footer

## Overview

The Footer component serves site visitors who arrive at the bottom of a page without finding what they want, typically containing information about the agency and navigation links.

## Properties

| Property | Attribute | Description | Type | Default |
| --- | --- | --- | --- | --- |
| `sx` | `sx` | Supports adding inline styles as an object | `any` | `{}` |

## Slots

| Slot | Description |
| --- | --- |
|  | The main footer content goes in the default slot. |
| `"cbp-footer-nav"` | Footer navigation links are slotted within this named slot. |
