# cbp-slider

## Overview

The Slider component allows for the selection of a value within a range, styled to design system specifications.

## Properties

| Property | Attribute | Description | Type | Default |
| --- | --- | --- | --- | --- |
| `context` | `context` | Specifies the context of the component as it applies to the visual design and whether it inverts when light/dark mode is toggled. Default behavior is "light-inverts" and does not have to be specified. | `"dark-always" | "dark-inverts" | "light-always" | "light-inverts"` | `undefined` |
| `disabled` | `disabled` | Specifies that the field is disabled. Primarily controlled by the parent `cbp-form-field` component. | `boolean` | `false` |
| `error` | `error` | Specifies that the field has an error (and sets aria-invalid accordingly). Primarily controlled by the parent `cbp-form-field` component. | `boolean` | `false` |
| `fieldId` | `field-id` | Optionally specify the ID of the visible control here, which is used to generate related pattern node IDs and associate everything for accessibility. For range sliders, "-start" and "-end" are appended to the specified/generated value automatically. | `string` | `createNamespaceKey('cbp-slider')` |
| `gap` | `gap` | Specifies the minimum difference in values in a range slider. If a non-zero value is specified, keep in mind the interaction with the "step" property. | `number` | `0` |
| `hideInput` | `hide-input` | Specifies whether the numeric input is hidden (shown by default). | `boolean` | `undefined` |
| `hideMinmax` | `hide-minmax` | Specifies whether the min/max values are hidden (shown by default). | `boolean` | `undefined` |
| `max` | `max` | Specifies the maximum value of the slider and numeric entry field (defaults to 100). This prop should be set on this component rather than (or in addition to) the slotted `input type="range"`. | `number` | `100` |
| `min` | `min` | Specifies the minimum value of the slider and numeric entry field (defaults to 0). This prop should be set on this component rather than (or in addition to) the slotted `input type="range"`. | `number` | `0` |
| `step` | `step` | Specifies the step value of the slider and numeric entry field (defaults to 1). This prop should be set on this component rather than (or in addition to) the slotted `input type="range"`. | `number` | `1` |
| `sx` | `sx` | Supports adding inline styles as an object | `any` | `{}` |
| `value` | `value` | Specifies the value of the slider and numeric entry field. It is highly recommended to set a contextually sensible default because the native `input type="range" cannot have an undefined or empty string as a value. If no value is specified, the default value will be reported (and submitted) as halfway between the specified minimum and maximum; unless the maximum is actually less than the minimum, in which case the default is set to the value of the minimum attribute. This prop should be set on this component rather than (or in addition to) the slotted` input type="range"`. |` number | number[] | string | string[] `|` undefined` |
| `variant` | `variant` | Specifies whether the control is a single slider or a range with two values (can be auto-detected by the number of slotted `input[type=range]` tags). | `"range" | "single"` | `"single"` |

## Events

| Event | Description | Type |
| --- | --- | --- |
| `valueChange` | A custom event fired when the value of the slider changes. | `CustomEvent<any>` |

## Methods

### `reset() => Promise<void>`

A custom method to reset the Slider component to its initial state and value since it does not update properly on a native form reset. This method may be called manually, but is automatically called on form reset when using the `cbp-form` component.

#### Returns

Type: `Promise<void>`
